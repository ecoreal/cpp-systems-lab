# Data_structure_normal

本目录收录数据结构课程和日常练习代码，适合按主题复习 C++ 基础数据结构。

## 内容范围

| 文件模式 | 主题 |
| --- | --- |
| `DS3.*.cpp` | 线性表、数组、指针等基础练习。 |
| `DS4.*.cpp` | 栈、队列或相关线性结构练习。 |
| `DS5.*.cpp` | 串、模式匹配或基础算法练习。 |
| `DS6.*.cpp` | 树结构相关练习。 |
| `DS7.*.cpp` | 图结构或遍历相关练习。 |
| `DS8.*.cpp` | 查找相关练习。 |
| `DS9.*.cpp` | 排序或综合算法练习。 |
| `DS10.*.cpp` - `DS14.*.cpp` | 后续章节和综合题。 |
| `midterm*.cpp` | 阶段测试或复习题。 |
| `fileDemo.cpp`、`get.cpp`、`test.cpp` | 文件、输入和临时验证代码。 |

## 运行提示

部分程序通过 `freopen("in.txt", "r", stdin)` 或 `freopen("out.txt", "w", stdout)` 读取/写入文件。运行时建议进入本目录：

```bash
cd Data_structure_normal
g++ -std=c++17 DS7.1.cpp -o /tmp/ds-7-1
/tmp/ds-7-1
```

## 阅读建议

- 先看输入输出，再看数据结构定义。
- 对链表、树和图代码，先画出结构变化过程。
- 对排序和查找代码，补充时间复杂度和边界样例。
- 对较长文件，可以先定位 `main()`，再沿调用关系阅读。
