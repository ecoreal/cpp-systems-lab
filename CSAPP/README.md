# CSAPP

本目录收录与 CSAPP 学习相关的 C/C++ 练习代码，主要用于理解计算机系统基础概念。

## 内容范围

- `CSAPP3e.2.*.cpp`：整数、位运算、移位、补码和浮点表示相关练习。
- `CSAPP_float_half.cpp`：浮点数位级处理练习。
- `CSAPP3e.3.*.cpp`：汇编、数据布局和过程调用相关练习。
- `CSAPP3e.7.*.cpp`：链接、符号和目标文件相关练习。
- `test.cpp`：临时验证代码。

## 运行示例

```bash
g++ -std=c++17 CSAPP/CSAPP3e.2.59.cpp -o /tmp/csapp-2-59
/tmp/csapp-2-59
```

## 阅读建议

阅读本目录时，建议配合教材章节、二进制表示草稿和调试器观察。重点不是记住某个答案，而是理解：

- 为什么补码表示可以统一加减法。
- 位移、掩码和类型转换如何影响结果。
- 浮点数为什么会出现精度损失。
- 编译、汇编和链接阶段分别解决什么问题。
